# Random Password Generator

## Description

This is a simple Python-based Random Password Generator developed as part of my Oasis Infobyte Python Programming Internship.

The program generates a random password based on the length and character types selected by the user.

## Features

- Allows the user to choose password length
- Supports uppercase letters
- Supports lowercase letters
- Supports numbers
- Supports symbols
- Generates a random password
- Validates minimum password length
- Handles invalid input
- Allows the user to generate another password

## Character Types

The user can choose from:

1. Uppercase letters
2. Lowercase letters
3. Numbers
4. Symbols

## Technologies Used

- Python
- Random module
- String module

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python password_generator.py

5. Enter the desired password length.
6. Select the character types.
7. The program will generate a random password.
