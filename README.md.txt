# BMI Calculator

## Description

This is a simple Python-based BMI Calculator developed as part of my Oasis Infobyte Python Programming Internship.

The program accepts the user's weight in kilograms and height in meters, calculates the Body Mass Index (BMI), and displays the corresponding BMI category.

## Features

* Accepts weight in kilograms
* Accepts height in meters
* Calculates BMI
* Displays BMI rounded to two decimal places
* Classifies BMI as:

  * Underweight
  * Normal
  * Overweight
  * Obese
* Handles invalid numeric input
* Validates negative or zero values

## Formula

BMI = Weight / (Height × Height)

## Technologies Used

* Python

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python bmi_calculator.py
```
