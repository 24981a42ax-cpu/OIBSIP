# Basic Weather App

## Description

This is a Python-based Basic Weather App developed as part of my Oasis Infobyte Python Programming Internship.

The application accepts a city name from the user and retrieves current weather information using the OpenWeatherMap API.

## Features

- Accepts city name from the user
- Fetches real-time weather information
- Displays temperature in Celsius
- Displays temperature in Fahrenheit
- Displays humidity percentage
- Displays weather condition
- Displays wind speed
- Handles invalid city names
- Handles empty input
- Handles invalid API keys
- Handles network and timeout errors

## Technologies Used

- Python
- Requests library
- JSON
- OpenWeatherMap API

## How to Run

1. Install Python.
2. Install the requests library:

py -m pip install requests

3. Add your OpenWeatherMap API key to the program.
4. Open the project folder in VS Code.
5. Run:

py weather_app.py

6. Enter a city name when prompted.
